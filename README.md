# InterVan
Aplicação web/mobile desenvolvida no Projeto Integrador do curso Informática para Internet Integrado ao Ensino Médio no IFSP - Campus Salto para apoiar a mobilidade urbana e o transporte por vans estudantis intermunicipais nas cidades próximas.

## Tecnologias
* **Mobile:** Kotlin
* **Back-end:** Node.js + TypeScript
* **Front-end Web:** HTML, CSS e TypeScript

## Estrutura do Projeto
* `/web` — Interface web (páginas HTML, estilos e scripts)
* `/backend` — API e regras de negócio em Node.js + TypeScript
* `/mobile` — Aplicativo em Kotlin
* `/docs` — Documentação, diagramas e protótipos do Projeto Integrador
